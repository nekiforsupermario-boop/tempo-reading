# Tempo — RSVP reading MVP

Рабочий статический MVP сервиса быстрого чтения. Открой `index.html` в браузере — сборка не нужна.

## Что уже есть

- вставка произвольного текста и демо-текст;
- RSVP-слово в центре экрана с ORP-подсветкой;
- скорость 100–1000 WPM;
- Play/Pause, назад/вперёд, начало заново;
- умные паузы на пунктуации и длинных словах;
- прогресс, оставшееся время и счётчик слов;
- адаптивный UI для телефона и ПК;
- локальное сохранение скорости, позиции настроек и onboarding;
- клавиатура: Space, ←/→, Ctrl/⌘+Enter;
- архитектура готова к вынесению строк RU/EN в словарь.

## Быстрый запуск

1. Открой `index.html` двойным кликом.
2. Нажми «Загрузить пример» или вставь свой текст.
3. Выбери скорость и нажми Play.

Для локальной проверки через сервер можно использовать любой статический сервер, например `npx serve .`.

## Проверка MVP

Проверены сценарии на уровне интерфейса: загрузка demo-текста, подсчёт слов, смена скорости, переход по словам, play/pause, окончание чтения, умные паузы, ORP-подсветка и сохранение настроек в localStorage. Для production следующими тестами стоит добавить unit-тесты таймингов и e2e-тест мобильной раскладки.

## Roadmap

1. Импорт PDF/EPUB и очередь чтения.
2. Библиотека с локальным хранением, затем аккаунты и синхронизация.
3. AI-режим: конспект, выделение терминов, адаптивная скорость.
4. Вопросы на понимание и аналитика прогресса.
5. Монетизация: freemium, Pro-подписка, годовой план и lifetime для первых пользователей.
6. Деплой на Cloudflare Pages/Vercel, аналитика активации и paywall после первых интервью.
